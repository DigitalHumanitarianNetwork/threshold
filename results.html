Run history

Every run is saved. Early runs had more questions that could not be scored because the judge step failed, so averages are not comparable between runs.

How it works

1. Ask

A GitHub Action reads the private question set and sends each question to the models being tested.

2. Score

An AI judge checks each answer against the key points of a reference answer written for that question.

3. Publish

Only aggregate scores are written to this public repository. Raw answers and answer keys are kept in private storage.
