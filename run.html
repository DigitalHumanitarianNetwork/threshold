Manual run

Run a model against a field

Runs are started by hand: when a new model appears, an admin or editor picks it here and runs it against a field's question set. Nothing runs on a schedule.

Only free-tier providers are on this list. The model's answers are scored by the judge against your ideal answers.
This run uses free AI limits. Every question goes to the model's provider and every answer goes to the judge. Free tiers cap how much you can send per day, so one big run can use up a provider's free quota. If a provider says no more today, the run stops and you can finish it another day.

What a run does

1. Sends each question to the model.
2. Saves the raw answers to the private sheet.
3. Asks the judge to score each answer against the ideal answer.
4. Writes the scores. Publishing them to the public site is a separate step, and it is always your choice.

A run takes a few minutes. Scores appear on the Results page when it finishes; raw answers land in the private spreadsheet.
